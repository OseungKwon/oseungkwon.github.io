## 앱 설치 없이 주문·결제까지 연결
SEO 오가닉 유저 대상의 웹 결제 서비스를 기획·개발하여 매출을 창출하고, 결제 이후 자연스럽게 앱 설치로 이어지도록 유도했습니다. 이 과정에서 프로젝트 전체 기획과 일정 관리, 웹 개발 전반을 총괄했습니다.

## 사용자를 고려한 이탈률 개선
결제 여정까지의 이탈률을 줄이기 위해 카카오싱크를 사용해 인증 허들을 낮췄으며, 인증 시점을 결제 직전으로 미루도록 기획했습니다. 그 결과 메뉴를 장바구니에 담은 사용자의 33%가 결제까지 완료하는 성과를 이뤘습니다.

## 결제 데이터 정합성 강화
장바구니 데이터의 상태 관리를 위해 zod를 통해 데이터를 검증하고, zustand와 세션 스토리지를 활용해 세션 동안 유지해야 하는 정보와 결제 정보와 같은 결제 시점에만 필요한 정보를 구분 및 저장했습니다.

PG사 장애에 따른 대응을 고려해 Firebase Remote Config로 결제수단과 PG 사를 유연하게 관리할 수 있도록 했습니다.

## 정책 변경에 대응하는 도메인 로직 분리
핵심 도메인 로직(할인·재고·금액 계산)을 순수 함수로 분리하고, 장바구니에는 파생값 대신 상품 및 옵션 참조만 보관하도록 구조를 설계했습니다. 서버 데이터는 엔티티 매퍼로 변환하여 UI 및 상태 코드와의 의존성을 격리했습니다.

이를 통해 개인컵 할인 정책 변경(별도 차감 → 상품가 차감) 시, 도메인 계산 함수와 단일 테스트를 수정하는 것만으로 3개 화면에 일괄 적용하며 중복 로직 구현 없이 신속하게 대응할 수 있었습니다.

## 프로젝트 성과

출시 후 웹 주문 사용자의 **객단가는 앱 사용자의 약 3배**를 달성했으며, 메뉴를 장바구니에 담은 사용자 중 **20%가 결제를 마쳤습니다**. 결제한 사용자 가운데 **32%는 앱을 설치**했으며, 절반 이상은 마케팅 수신에 동의했습니다.
