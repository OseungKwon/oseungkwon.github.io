## 카카오싱크 기반 이벤트 참여 인증 간소화

기존 이벤트는 참여 전에 휴대폰 번호를 직접 입력하고 인증해야 했습니다.

웹앱과 이벤트 서비스의 인증 흐름을 카카오싱크로 전환해, 카카오 인증으로 참여에 필요한 사용자 정보를 수집하고 신규 사용자의 입력·인증 단계를 줄였습니다.

## iOS 인증 후 복귀 경로 개선

iOS에서는 카카오 인증을 마친 뒤 브라우저로 자동 복귀하지 않아 사용자가 직접 돌아와야 했고, 이 구간에서 참여를 중단하는 사용자가 많았습니다.

인증 후 카카오톡 인앱뷰에서 이벤트 참여를 이어가도록 **퍼머링크를 이용한 복귀 방식을 제안·적용**했습니다. 사용자가 브라우저로 직접 돌아와야 하는 단계를 없앴으며, 적용 이후 **친구 초대 이벤트 참여 성공률은 32%에서 38%로 6%p 상승**했습니다.
