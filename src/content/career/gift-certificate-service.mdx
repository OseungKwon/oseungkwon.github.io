## 상품권 발행·수신 플로우 구축

사용자가 상품권을 구매해 선물하면 수신자가 웹에서 선물을 확인하고 앱에 등록해 사용할 수 있는 상품권·선물하기 서비스를 개발했습니다. 운영팀의 상품권 생성·발행 백오피스부터 B2C·B2B 수신자 웹과 앱 등록 플로우까지 프론트엔드 전반을 담당했습니다.

서비스 출시 이후에도 상품권 유형 추가, 기업 대량 발송, 수신자 웹 개선, 정산 화면 구축 등 비즈니스 확장에 필요한 기능을 지속적으로 개발하고 운영했습니다.

## 운영·정산 영역 확장

서비스가 확장되면서 시즌 상품권과 B2B 발행 유형, 판매 상태와 발송 내역 관리 기능을 추가했습니다. 이용안내와 약관은 클라이언트 코드에 직접 포함하던 방식에서 서버에서 관리하는 구조로 전환해, 정책이 바뀔 때마다 프론트엔드를 다시 배포해야 하는 의존성을 줄였습니다.

이를 통해 상품권의 생성·발행부터 수신·앱 등록, 기업 대량 발송과 정산까지 이어지는 **B2C·B2B 선물 커머스 운영 기반을 구축**했습니다.

**사용 기술:** React, TypeScript, Angular, Dynamic Link, Deep Link, Web API
